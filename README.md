# 📋 NAAC Activity Report Tool

> **An internal IQAC tool for filling, formatting, and downloading institutional activity/event reports — fully aligned to NAAC's Binary Accreditation Framework (10 Attributes).**

🔗 **[Open the Tool →](https://YOUR-USERNAME.github.io/naac-report-tool)**

---

## What This Tool Does

This is a browser-based form that guides faculty coordinators through filling out a complete NAAC-compliant activity report in 9 structured sections. Once filled, it generates and downloads a formatted **Word document (.doc)** ready for IQAC submission, SSR evidence folders, or DVV verification.

No login. No installation. Works on any browser.

---

## Key Features

| Feature | Detail |
|---|---|
| 🗂 **9-Section Guided Form** | Institution details, participation, NAAC mapping, event description, learning outcomes, impact, feedback, documents checklist, approval |
| 📊 **NAAC 10 Attributes Mapping** | All 47 sub-attributes with multi-select relevance tagging per indicator |
| 🤖 **AI-Assisted Report Writing** | Claude AI polishes your draft into formal NAAC-quality academic English |
| 📄 **Word Export** | Generates a formatted, print-ready `.doc` file instantly |
| ✅ **Evidence Checklist** | 15-item document checklist with Enclosed Y/N and link fields |
| 📐 **OBE Mapping** | PO/CO alignment, Bloom's Taxonomy, Graduate Attributes, SDG alignment |

## NAAC Attributes Covered

The tool maps events to all **10 Attributes** of the NAAC Binary Accreditation Framework:

### 🔵 INPUT Attributes (Weightage: 25%)
| # | Attribute | Sub-Indicators |
|---|---|---|
| 1 | Curricular Aspects | Curriculum Design, Academic Flexibility, Enrichment, Feedback, IKS |
| 2 | Teaching-Learning & Evaluation | Student Profile, Diversity, T-L Process, Faculty Quality, Evaluation, Learning Outcomes, Satisfaction |
| 3 | Research, Innovation & Extension | Resource Mobilisation, Innovation Ecosystem, Publications, Extension, Collaboration |

### 🟦 PROCESS Attributes (Weightage: 75%)
| # | Attribute | Sub-Indicators |
|---|---|---|
| 4 | Infrastructure & Learning Resources | Physical Facilities, Library, IT Infrastructure, Maintenance |
| 5 | Student Support & Progression | Support, Progression, Participation, Alumni Engagement |
| 6 | Governance, Leadership & Management | Vision & Leadership, Strategy, Faculty Empowerment, Financial Management, IQAC |
| 7 | Institutional Values & Best Practices | Values & Social Responsibility, Best Practices, Distinctiveness |

### 🟢 OUTCOME Attributes (Weightage: 75%)
| # | Attribute | Sub-Indicators |
|---|---|---|
| 8 | Student Outcomes | Placement, Higher Education, Awards, PhD, Entrepreneurship |
| 9 | Research & Innovation Outcomes | Patents, Publications, Start-up Ecosystem, Faculty Recognition |
| 10 | Sustainability & Green Initiatives | Green Campus, Rankings, Community Impact, International Activities |

## How to Use

1. **Open the tool** using the link above
2. **Fill each section** — the sidebar tracks your progress across all 9 sections
3. In **Section B**, expand each NAAC Attribute and select the relevant sub-attributes for your event
4. Click **Generate & Download Report** on the last section
5. The tool produces a formatted **Word document** — save it to your IQAC evidence folder

> 💡 The AI writing assistant will automatically polish the detailed event report narrative into formal academic English suitable for SSR submission.

## Sections at a Glance
